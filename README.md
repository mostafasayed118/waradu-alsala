# ورد الصلاة 🌹

تطبيق Flutter محلي للتذكير بقول الصلاة على النبي ﷺ

## فكرة التطبيق

تطبيق عربي بسيط يذكّر المستخدم بقول:

> اللهم صلِّ على سيدنا محمد وعلى آل سيدنا محمد

ويتيح له تسجيل عدد المرات التي قال فيها الصلاة على النبي ﷺ عبر عدّاد واضح وسهل الاستخدام.

## المميزات

- ✅ عدّاد ذكي مع حفظ تلقائي
- ✅ تذكيرات محلية متكررة أو في أوقات محددة
- ✅ واجهة عربية كاملة باتجاه RTL
- ✅ وضع فاتح وداكن
- ✅ اهتزاز خفيف عند الضغط
- ✅ زر تراجع لإلغاء آخر زيادة
- ✅ إعادة تعيين مع تأكيد
- ✅ يعمل محلياً بالكامل بدون إنترنت
- ✅ لا جمع بيانات ولا تتبع

## المتطلبات

- Flutter SDK >= 3.12.2
- Dart SDK >= 3.12.2
- Android Studio أو VS Code
- جهاز Android أو iOS أو محاكي

## طريقة التشغيل

### 1. تثبيت الاعتماديات

```bash
flutter pub get
```

### 2. تشغيل التطبيق

```bash
flutter run
```

## بناء التطبيق

### Android

```bash
flutter build apk --release
```

الملف الناتج سيكون في: `build/app/outputs/flutter-apk/app-release.apk`

### iOS

```bash
flutter build ios --release
```

ثم افتح مشروع Xcode لرفع التطبيق على App Store.

## الصلاحيات المستخدمة

### Android

| الصلاحية | السبب |
|----------|-------|
| `RECEIVE_BOOT_COMPLETED` | استعادة جدولة الإشعارات بعد إعادة تشغيل الجهاز |
| `VIBRATE` | الاهتزاز الخفيف عند الضغط على زر العدد |
| `SCHEDULE_EXACT_ALARM` | جدولة الإشعارات في أوقات محددة |
| `POST_NOTIFICATIONS` | عرض الإشعارات (Android 13+) |

### iOS

| الصلاحية | السبب |
|----------|-------|
| `NSUserNotificationsUsageDescription` | إذن عرض الإشعارات للتذكير بالصلاة |

## هيكل المشروع

```
lib/
├── main.dart                 # نقطة البداية
├── models/
│   ├── counter_data.dart     # نموذج بيانات العداد
│   └── app_settings.dart     # نموذج إعدادات التطبيق
├── providers/
│   ├── counter_provider.dart # مدير حالة العداد
│   └── settings_provider.dart # مدير حالة الإعدادات
├── screens/
│   ├── home_screen.dart      # الشاشة الرئيسية
│   ├── settings_screen.dart  # شاشة الإعدادات
│   └── about_screen.dart     # شاشة حول التطبيق
├── services/
│   ├── storage_service.dart  # خدمة التخزين المحلي
│   └── notification_service.dart # خدمة الإشعارات
└── utils/
    └── app_theme.dart        # ثيم التطبيق
```
